# App icon

Status: Icon Composer source and 1024 preview are in `Icon/`. The app bundle
is wired to compile and ship it.

## Concept

An open archive tray with two glass file cards rising out of it. The coral
sunset tile is the Quark energy; the mint card is the file you came to find.
One object, one action: look inside the container.

No text, no letters, no SF Symbols, no 7-Zip mark, no screenshot of the UI.

## Grid

| Measure | Value |
| --- | --- |
| Canvas | 1024 x 1024 |
| macOS tile | 824 x 824, centered at 100 px margin |
| Tile corner radius | 185 |
| Glyph width | 520, about 51 percent of the canvas |
| Glyph height | 530, centered |
| Card width | 260 |
| Tray width | 520 |
| Tray height | 300 |

The Icon Composer layers are full-canvas 1024 files. The system draws the
rounded mask, glass, highlights, shadow, and the dark, tinted, and clear
looks. The standalone `AppIcon.svg` is a brand preview with the tile drawn in,
not the source for the app icon.

## Layers

```text
Icon/AppIcon.icon/
  icon.json
  Assets/box.svg      white open tray, one filled path
  Assets/cards.svg    white back card, mint front card with folded corner
```

`box.svg` sits on top, `cards.svg` sits behind it. Both use glass. The group
uses a neutral shadow and 0.25 translucency. `automatic-gradient` on coral
`srgb:0.98,0.33,0.42` lets the system add the soft background light.

## Palette

| Role | Color |
| --- | --- |
| Background | automatic coral gradient |
| Tray | white glass |
| Back card | white, 0.78 to 0.58 opacity |
| Front card | mint `#8CFFD6` with a white folded corner |
| Shadow | neutral system shadow |

Dark, tinted, and clear variants are generated by the system. The glyph stays
one shape and one reading in every look.

## Files

- `Icon/AppIcon.icon/` - source, committed.
- `Icon/AppIcon.svg` - standalone 1024 vector preview.
- `Icon/AppIcon-1024.png` - rendered default look, 1024 px.
- `Icon/AppIcon-review.png` - contact sheet: default, dark, tinted dark, clear
  light at 256 pt, then default at 32 and 16 pt.
- `Resources/Assets.car` and `Resources/AppIcon.icns` - generated, ignored by
  git, rebuilt by `tools/make_icon.sh`.

## Checks

```bash
tools/make_icon.sh
tools/icon_review.sh
./build.sh
plutil -p ~/Applications/QuarkZip.app/Contents/Info.plist | grep -i icon
```

The review sheet shows a clear tray, a readable mint card, and a recognizable
silhouette at 16 pt. The app bundle carries `Assets.car` and `AppIcon.icns`,
and `CFBundleIconName` is `AppIcon`.

## Rules

- Do not draw the rounded square, margin, shadow, or sheen in the layers.
- Do not add text, letters, or an SF Symbol.
- Keep the glyph between 45 and 55 percent of the canvas.
- Filled shapes only. A stroke on an open path leaves a faint glass line.
- Re-run both tools after every layer or palette change.
